# vergi-duygu-analizi

Türkçe yorumlar için kural tabanlı duygu analizi uygulaması (Streamlit).

## Çalıştırma

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud'da yayımlama

1. https://share.streamlit.io adresinde GitHub hesabınızla giriş yapın.
2. "New app" ile bu depoyu, `main` dalını ve ana dosya olarak `app.py` seçin.
3. "Deploy" düğmesine basın.

Analiz kural tabanlıdır ve hata yapabilir.
